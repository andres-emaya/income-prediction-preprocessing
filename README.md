# The Impact of Advanced Preprocessing Techniques on Machine Learning Models for Income Prediction

📄 Published in *Ahliya Journal of Business Technology and MEAN Economies*, 3(1), 39–46 (2026). [Read the paper](https://doi.org/10.59994/ajbtme.2026.3.39)

Code for the paper. A leakage-free preprocessing pipeline for the Adult Income dataset: cleaning, imputation, one-hot encoding, variance-based feature selection and a cross-validated search over outlier clipping, scaling, Yeo-Johnson transformation and SVD, compared across four models.

**Models:** Histogram-Based Gradient Boosting, Random Forest, Logistic Regression, Linear SVC

**Results:** Histogram-Based Gradient Boosting performed best, with 86.8% test accuracy and 0.921 ROC-AUC.

**Dataset:** [Adult (UCI Machine Learning Repository)](https://archive.ics.uci.edu/dataset/2/adult). The notebook runs in Google Colab and asks you to upload `adult.csv`.

**Built with:** Python, scikit-learn, pandas, NumPy, Matplotlib
